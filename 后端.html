4前端接入约定（对齐前端入口页）

统一响应信封 { code, message, data }；code === 0 表示成功
业务失败的状态码 HTTP 200 + body.code ≠ 0（唯一例外：401 类返回真实 401）。 按 RESTful 习惯去断言 400/404 会全部判错
鉴权 Authorization: Bearer <JWT>；JWT 带 ver（对齐 users.token_version） 与 jti（登出黑名单）
越权判定顺序 无 Token → 401/40101 → Token 失效 → 401/40102 → 非管理员 → 403/40301（顺序不可换）
管理端 /api/v1/admin/* 需 role = admin，是数据隔离的唯一显式例外，全操作留审计
任务耗时口径 端到端不超过 60 s；预测为同步语义（响应返回时任务已入终态， 不存在运行期可轮询的进度窗口）

错误码区间

区间含义典型值
400xx请求与数据校验 40001 缺少必需列 · 40005 时间断档 · 40011 密码强度不足 · 40012 参数非法
401xx认证 40101 未登录 · 40102 Token 失效 · 40103 邮箱或密码错误 · 40104 限流冷却 · 40105 邮箱已注册
403xx权限40301 无权访问他人资源
404xx不存在 40401 任务不存在 · 40402 数据集不存在 · 40403 用户不存在 · 40404 无启用模型
500xx服务端内部 50001 推理失败 · 50002 文件读写异常 · 50003 数据库异常
