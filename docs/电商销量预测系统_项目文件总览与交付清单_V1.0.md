## 二、源代码层

### 2.1 `app/` —— 后端（FastAPI + PyTorch，⏱️ 13,143 行）

| 子目录 | 内容 | 关键文件 |
|---|---|---|
| `app/algo/` | **算法层（10 个 .py，含 `__init__.py`）**，本项目唯一可独立于 Web 运行的资产 | `preprocess.py`（缺失插值 + 尖峰截断）、`features.py`（滑动窗口 + 日历 / 滞后 / 滚动特征）、`model.py`（多层 LSTM）、`train.py`（MSE + Adam + 学习率衰减 + 早停）、`infer.py`、`metrics.py`（MAPE / MAE / RMSE）、`classify.py`（A/B/C 需求分类）、`fallback.py`（三级降级）、`config.py` |
| `app/api/` | HTTP 路由层 | `health.py`（`API-21` `/health`）、`v1/auth.py`、`v1/datasets.py`、`v1/predictions.py`、`v1/history.py`、`v1/admin.py`、`v1/router.py` |
| `app/core/` | 基建层 | `config.py`（Settings + 内置 .env 加载器）、`db.py`（engine / PRAGMA / `init_db`）、`deps.py`（`get_db` / 鉴权依赖）、`errors.py`（全量错误码 + 处理器）、`logging.py`（request_id + 敏感字段遮蔽）、`middleware.py`、`security.py`（bcrypt + JWT）、`model_holder.py`（模型单例） |
